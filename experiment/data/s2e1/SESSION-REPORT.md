## 核心发现

1. **图文顺序完全决定输出形态与事实性**（t=0.0 确定性解码下）：
   - text→image：模型先看到"风扇在中心吗"的问题，**顺着问题把图像读成风扇确认**——20/20 输出
     "There is a black industrial fan in the center of the image."（格式漂移 + 幻觉）
   - image→text：模型先看图，诚实回答 20/20 "No."（格式合规 + 语义全对）
2. **历史"静态图不复现/实时帧才复现"结论的主要混杂是图文顺序**：
   - C 客户端（板端实时链路）= text→image → 句子漂移
   - Python 静态脚本 = image→text → 单词 Yes.
   - 08-12 的静态无缓存对照（image→text）与在线 C 链路（text→image）的差异，顺序因素与输入序列因素此前未分离
3. **"引导性问题"效应在小 VLM 上极端化**：text 在前时模型服从问题预设而非图像证据；对边缘部署的
   直接启示：**yes/no 检测请求应把图像放在文本之前**（或固定 image→text 顺序）

## 结论边界

- 仅负样本场景（风扇不在）；正样本场景的同款实验待用户把风扇放回后补做（预期验证 text→image 在
  正场景是否仍漂移——历史 C 链路 640×480 数据表明会）
- 单一场景 20 连续帧：帧间独立性强于单帧重复，但同场景相关；效应 100% 一致（20/20 同方向），
  p=1.9e-6 无需更多样本即可定论顺序主效应
- temperature=0.0 确定性解码：结论是模型确定性行为，非采样噪声
- 分辨率与顺序的交互未测（历史 C 链路 320×240 在 text→image 下仍 100% 单词 → 顺序效应与分辨率效应
  存在交互，320 的低细节可能压制了"引导式确认+描述"行为）
