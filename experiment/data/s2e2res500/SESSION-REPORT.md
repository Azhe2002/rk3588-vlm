## 运动污染警示（用户现场报告 + 帧差证据）

- 用户报告：实验期间有人为干扰经过风扇前方；指示"No."输出不作为模型判断错误
- 帧差证据：160×120 批次（本实验最先采集）帧间差 f_07→f_14 达 2.0–8.99
  （历史稳定场景均值 0.4–0.95）——**采集阶段有人/物经过画面**
- 3 个 "No."（f_01, f_02, f_12）中 f_12 明确处于大运动窗口；f_01/f_02 帧差 1.5–1.7 偏高
- **结论**：160×120 组 3 个 No 可能为遮挡/运动干扰的真值变化，不作模型感知失败的证据

## 与 256M 对比（image→text 固定）

| 分辨率 | 256M 语义 | 500M 语义 |
|--------|----------|----------|
| 160×120 | 0/20 全 No（场景稳定，帧差 <2） | **20/20 全 Yes（稳定场景重跑 s2e2res500r 确认，帧差最大 3.74）** |
| 320–1280 | 全 Yes | 全 Yes |

- **两模型在 ≥320 全分辨率：格式 100% + 语义 100%**——历史全部崩塌/摇摆现象在观察式顺序下均消失
- 历史 500M@320 语义摇摆（41%↔95%）与 500M@640 0% 格式崩塌均为 text→image 引导效应产物
- **160×120 呈现模型规模相关的低端感知阈值**（双稳定场景验证）：256M 诚实 No（感知失败），500M 感知保持 Yes

## 运动污染事件记录（方法论价值）

- 首跑 500M@160 出现 3 个 "No." + 现场报告人为经过 → 帧差检测（最大 8.99，稳定基线 <2）确认采集期污染
- 稳定场景重跑（s2e2res500r）：20/20 全 Yes，帧差最大 3.74
- 教训：**帧差监测是边缘实验的必备质控**——本实验因此避免了一个伪"感知失败"结论
