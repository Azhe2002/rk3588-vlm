## 结论

1. **σ=1 的格式恢复不能归因于 videoconvert 管线插入（sham 对照目标达成）**：零模糊双转换组 5/32 单词，无任何恢复（p=0.0036 反而显著低于基线）→ 恢复来自模糊本身。videoconvert 双转换甚至轻度恶化格式（JPEG 29.7KB > 基线 25.2KB，颜色往返可能增加"色彩细节感"），或存在会话内时序混杂——无论哪种，方向都不支持管线效应解释。
2. **σ=1 在负场景下同时消除确认幻觉（新证据）**：语义 yes 32/33 → 0/32（Fisher p=3e-16），32/32 诚实 "No."。与 08-12 正场景 σ=1（100% 格式 + 100% 语义正确 Yes）合并：**σ=1 把模型从"引导式确认"推回"诚实观察者"状态，格式与语义都跟随真值**。
3. **实时链路负场景幻觉率 97%（32/33）**：与 S2-E1 冻结帧 20/20 一致 → 确认幻觉在实时链路同强度发生（顺序主导，实时性不改变幻觉率）。
4. **σ 与 S2-E5 grammar 的对比**：grammar 硬保格式但幻觉保留（neg640 20/20 "Yes."）；σ=1 同时修复格式+语义——但 σ 是**信息破坏型修复**（JPEG 22.5KB < 25.2KB；σ≥7 感知失败全 No），而 v0.3 顺序修复零信息损失。机制意义：**text→image 的幻觉不是不可逆的模型固有属性，而是"引导强度 × 细节证据"的连续体**——降低证据可以把模型推回诚实状态。
