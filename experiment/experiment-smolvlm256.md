# 实验：SmolVLM-256M 板端连续采图推理性能测试

> 实验日期：2026-08-07
> 测试平台：RK3588S (Debian 11, 192.168.1.8)
> 测试程序：`/userdata/llama/bin/rk3588-vlm` (main 主程序, v3)

---

## 1. 实验目的

- 验证 SmolVLM-256M 在 RK3588 CPU 上的真实端到端单帧推理耗时
- 与 SmolVLM-500M（历史数据 8-9s/帧）做性能对比基准
- 用 main 主程序（真实采集链路：相机取帧 → llama-server 推理）测量，排除固定图片 KV cache 干扰

## 2. 测试配置

| 项目 | 值 |
|------|-----|
| 模型 | `SmolVLM-256M-Instruct-Q8_0.gguf` (167MB) |
| mmproj | `mmproj-SmolVLM-256M-Instruct-Q8_0.gguf` (99MB) |
| 推理服务 | llama-server (板端常驻, port 8088) |

| 测试图 | 实时采集帧（黑色工业风扇画面） |

## 5. 关键发现

1. **真实单帧耗时 ≈ 5.4-5.5s**：main 主程序每轮重新取帧（JPEG 内容变化），无 KV cache 命中，全部为真实推理时间
2. **耗时构成**：图片编码（约 4.5s）+ 生成（约 1s），与 500M 的耗时构成模式一致
3. **稳定性好**：10 轮波动 <3%，无异常帧
4. **识别准确**：10/10 全部输出 `YES`，与画面内容（黑色工业风扇）一致
5. **对比 500M 历史数据**（8-9s/帧）：256M 快约 **38%**
